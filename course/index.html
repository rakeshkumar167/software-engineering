Ideas for further modules

Each of these builds on the modules above.

  • Object-oriented, functional and other paradigms in depth.
  • Type systems and static analysis (TypeScript, mypy, generics).
  • Regular expressions and text processing.
  • Advanced SQL and data modelling: query planning, replication, sharding, migrations at scale.
  • Distributed systems: CAP theorem, consensus, queues and event streaming (Kafka), eventual consistency.
  • System design interviews and architecture: monoliths vs microservices, scaling patterns, capacity estimation.
  • Mobile development and cross-platform apps; desktop apps.
  • Frontend frameworks: React/Vue/Svelte, state management, accessibility (a11y), performance (Core Web Vitals).
  • Cryptography basics: hashing, symmetric/asymmetric encryption, signatures, PKI.
  • Data engineering and ML basics: pipelines, notebooks, model evaluation.
  • Infrastructure as Code (Terraform), Kubernetes in depth, SRE practices.
  • Agile, estimation and working in teams; writing specs and documentation; open source contribution.
  • Career skills: reading unfamiliar codebases, technical communication, portfolios.
  • Capstone project: build, test, containerise, deploy and monitor a small full-stack app.
